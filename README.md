
### data/ - Data Files
- `sample_info/` - Sample metadata tables
- `drug_tissuetox/` - Drug susceptibility scores aggregated at the tissue level across 295 drugs
- `sample_tox/` - Sample-level drug susceptibility scores for individual single-cell datasets
- `null_distribution/` - Reference null distributions for statistical significance testing of drug susceptibility scores
- `hbca/` - Processed data for the breast tissue case study (GSE235326)

### scripts/ - Script Files
- `preprocess/` - Data preprocessing scripts
- `prediction/` - Drug susceptibility prediction scripts
- `null_distribution/` - Generation and visualization of null distributions
- `plot/` - Visualization scripts for main and supplementary figures
